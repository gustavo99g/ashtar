## Vindos do BACKLOG

- [x] **Identidade falsa nova a cada entrada** (`idiot-<uuid>`, nome `Idiota-<uuid>`): a API passou a ter
      identidade do dispositivo, membros e sessão (Etapas 2 e 3). **O app só passa a usá-las na v0.2.2**
      (`BACKLOG.md`); até lá, o id aleatório por entrada evita colisão no LiveKit.
- [x] **Permissão do beta pela API:** a API devolve o canal de atualização de cada usuário (substitui a
      variável `ASHTAR_UPDATE_CHANNEL`); o dono marca e desmarca pelo `admin` (Etapa 4) e está sempre no
      beta. A tela de usuários vem com a UI nova (v0.2.2).

## Antes de usar

- [x] **Backup fora do computador** configurado e uma restauração testada **antes** de qualquer membro entrar
      (Etapa 5): diário, pelo Agendador do Windows, com a cópia no Cloudflare R2.
- [x] **`DATABASE_URL` no `.env`** da API e no `.env.example`.
- [x] **Criar o dono pelo `admin`** e gerar uma recuperação para vincular o computador do dono (decisão 5 do
      plano). **Adiado para a v0.2.2** (`BACKLOG.md`), quando o app passar a usar as rotas.

## Riscos e cuidados

- [x] **O `admin` é temporário** (Etapa 4 do plano): quando a UI da v0.2.2 cobrir a administração, tirar
      os comandos que ela substituir e deixar só `dono` e `backup`. Até lá, não investir nele além do básico.

- [x] **Rota antiga aberta** (adiado para a v0.2.2, `BACKLOG.md`): enquanto o app não usar as rotas novas, `/api/voice/join` continua aceitando
      o código de acesso provisório. Só a parte visual desliga isso e sobe o `MIN_CLIENT_VERSION` (ADR 0011).
- [x] **Limite de tentativas global:** quem errar convites de propósito trava os convites de todos por até
      10 minutos; o login fica fora do limite (decisão 3 do plano; ADR 0011).
- [x] **Convite de grupo que vaza** deixa entrar quem o viu enquanto vale; o limite de usos, a validade
      curta, o `revogar` e o `remover` seguram isso.
- [x] **Trocar a placa-mãe** exige um convite de recuperação (ADR 0011).
- [x] **`COLLATE NOCASE` só ignora maiúsculas no ASCII:** "JOÃO" e "joão" contam como nicks diferentes
      (ADR 0010).
- [x] **Escritas simultâneas do `admin` e da API** esperam até 5 s (`busy_timeout`); o `admin` grava com a
      API no ar (ADR 0010).
- [x] **Comparação do código de acesso** em `client_policy.rs` não é de tempo constante; aceitável para o
      grupo atual, rever na VPS (v0.2.6).
