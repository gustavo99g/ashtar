## Riscos e cuidados

- [x] *(aceito: regra permanente: cada rota nova passa pela regra de acesso)* **Privacidade é o risco principal da fase.** Qualquer rota ou evento novo tem de passar pela regra de
      leitura; os testes de vazamento rodam no pipeline e não podem ser pulados.
- [x] *(obsoleto: a v0.3.1 saiu inteira)* **A v0.3.1 é grande** (onze etapas). Se apertar, o corte é publicar as conversas com as não lidas
      (Etapas 7, 8, 11, 12 e 13, mais o ponteiro da 9) e deixar menções, silenciar e status numa `0.3.11`.
- [x] *(provado no uso, até a 0.8.11)* **O tempo real com destinatário muda o caminho de todos os eventos.** Um erro ali derruba o chat
      inteiro: a Etapa 8 sobe sozinha na API e roda uns dias com o app atual antes do resto.
- [x] *(aceito: depende do Windows de cada um)* **As notificações dependem do Windows de cada um** (modo de foco, notificações desligadas para o app).
      O aviso do canto e as não lidas não podem depender delas.
